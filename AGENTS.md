# data-analysis-journalism Skill

AI agent skill for journalistic exploratory data analysis.

## Project structure

- `SKILL.md` — Skill definition (8-step EDA workflow)
- `references/eda-checklist.md` — Statistical tests, ecological fallacy explainer, denominator guide
- `evals.json` — Evaluation prompts for skill testing

## Testing

Run the evals in `evals.json` manually by activating the skill and running each prompt.
Pass threshold: all scoring_criteria met per eval.
